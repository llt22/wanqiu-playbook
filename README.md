# 修仙沙雕动画改编手册

用 AI 把小说《我来给修仙界上点强度》改编成沙雕动画时，**为什么这么改**和**怎么改**的依据，统一放这个仓库。
分集项目只放剧本、代码、音频和成片，不再各存一份规范。

对标 B 站 UP 主“在下晚秋”的修仙沙雕动画《云深不知处然有六出焉》（原作者已因版权停更）。
只还原节奏、镜头、台词，画面用代码画的占位角色；台词取自原著，仅作技术试验。

## 目录

| 文件 | 内容 | 什么时候改 |
|---|---|---|
| [`ANALYSIS.md`](ANALYSIS.md) | 对标分析：观众数据、五条“像朋友”的机制、五种疏离写法、UP 主第 1 集与原著 1–2 章的逐句对照、节奏制作规格 | 只有拿到新证据时才改（新的抽样数据、新的对照结论） |
| [`ADAPTATION.md`](ADAPTATION.md) | 改编规范：不拍闪回、主角默认在场、台词只改三类、镜头节奏、声音、连载规则 | 每集开工前读，原则变了才写回来 |
| [`CAST.md`](CAST.md) | 角色表：代号、造型（袍色/发型/配饰）、音色、语气、配音模型与配额 | 新角色出场前先补表；音色一旦定了不要换 |

## 和分集项目的关系

- 分集项目（如 `wanqiu-ep199`、`wanqiu-ep200`）是独立 git 仓库，只放 `shots.json`、`src/`、`scripts/`、`audio/`、`NOTES.md`、`SCRIPT.md`。
- 分集项目里的角色代号（`wq`、`tz`、`xz`……）是 `CAST.md` 的键，`shots.json` 的 `who` 字段和 `src/theme.ts` / `src/Character.tsx` 的分支都按它来。
- 每集的做法记录、音色实测、自检结果写在各项目的 `NOTES.md`，不进这个仓库。

## 维护规则

1. 新原则先落到 `ADAPTATION.md`，并在 `ANALYSIS.md` 里写清依据（哪一集、哪条证据、谁的说法）。
2. 新角色先补 `CAST.md`，造型和音色都要和老角色区分得开；同一音色不要分给两个会碰面的角色。
3. 一集做完，把踩到的坑回写到 `ANALYSIS.md` 末尾的经验节，别只留在对话里。
